# 任务中心

头像左侧入口展示最近 6 条任务，进行中数量包含排队、执行与自动重试；红点仅表示最终失败。
桌面使用 Popover，窄屏使用 Sheet；“查看全部任务”进入 `/tasks`，支持资源名称/ID、类型、状态、时间筛选与分页。

## 数据与状态

- `/api/tasks` 为只读分页视图，合并 `sys_sync_task`、`sys_sync_event` 和节点发布目标，所有查询按当前租户限定。
- `/api/tasks/:id` 用资源 ID 与版本共同定位详情，避免同一发布的多个节点或旧版本结果串扰。
- `/api/tasks/:id/history?version=...` 返回最近 100 条保留的同步尝试，并标明是否截断。
- 同步调度仍使用原有合并标记和版本栅栏；此功能不新增调度器，也不改变重试策略。
- 同步标记未完成且已有失败时显示“重试中”。同一版本保留的记录中存在失败，之后完成时显示“已恢复”。
- 节点发布只有服务端记录了应用结果才显示成功。允许重试的失败显示“重试中”；不可重试失败显示“失败”。旧发布已被替代或节点被排除时显示“已结束”。
- 同步尝试沿用 7 天保留策略。已被覆盖且只有失败记录的旧版本显示“已结束”，不会计入当前失败数量。
- 迁移 `0021_task_history_error` 保存新同步结果的错误快照；升级前未保存的历史错误无法还原，详情会明确说明。

## 实时更新

复用现有同步与节点 SSE 连接。同步任务提交、领取、结果提交后通知前端，`task-state` 失效任务查询；节点变化使用 `node-state`。重连 `ready` 重新核对数据库。没有定时 HTTP 轮询。

SSE 心跳携带数据，以便浏览器实际分发事件。终止状态的连接在 3 秒后重新建立；代理残留的无响应连接在连续 45 秒没有事件后重新建立。正常心跳和状态事件会重置这个超时，卸载页面会关闭连接并清除定时器。

后台任务的短暂失败不再逐次弹出失败通知，用户可在任务中心查看重试和恢复。资源查询刷新本身失败仍保留错误提示。

## 验证边界

必须同时验证新建数据库迁移、真实本地服务的鉴权与列表/详情接口，以及浏览器桌面/窄屏交互。测试数据必须放在隔离数据库；浏览器中的测试记录不代表生产 DNS 或真实节点执行结果。

集成验证脚本：先在名称以 `_task_center_qa` 结尾的本地空数据库启动 Server 执行迁移，再设置标准 `PGHOST/PGPORT/PGUSER/PGPASSWORD/PGDATABASE` 环境变量，运行 `python tests/task_center_read_model_test.py`。默认回滚测试数据；加 `--keep-fixture` 后可运行 `TASK_QA_PASSWORD` 指定本地管理员密码的 `python tests/task_center_http_test.py`，或用浏览器检查实际页面。`PSQL` 可指定 PostgreSQL 客户端绝对路径。
